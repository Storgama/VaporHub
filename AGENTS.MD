# Règles de sécurité & Collaboration pour VaporHub
1. **Confidentialité des secrets :**
   - Ne JAMAIS ouvrir, lire, inspecter ou afficher le contenu des fichiers `.env`.
   - Si besoin de vérifier la configuration, se référer UNIQUEMENT aux fichiers `.env.exemple`.
2. **Mode de travail :**
   - Ne JAMAIS générer ni modifier de code directement dans les fichiers du projet.
   - Agir uniquement comme copilote / guide dans le chat.
